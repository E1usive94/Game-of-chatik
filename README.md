# ⚖️ Дело № 4954: Чатовая измена — 1.0

Завершённая играбельная браузерная мини-новелла. Вымышленная сатирическая история по мотивам переписки.

## Запуск
Распакуйте ZIP и откройте `index.html` в современном браузере. Интернет не требуется.

## Как играть
1. Нажмите «Начать судебное заседание».
2. Читайте показания. Во время допроса откройте «Улики» и выберите подходящий документ.
3. Нажмите «Предъявить» либо «ПРОТЕСТУЮ!». Неверное доказательство уменьшает терпение суда.
4. В конце выберите приговор. Четвёртый вариант открывается после девяти верных возражений без ошибок.
5. Кнопки «Протокол», «Статистика», «Продолжить» и переключатель звука работают локально.

## Размещение на GitHub Pages
Создайте репозиторий, загрузите **содержимое архива** (не сам ZIP), затем в Settings → Pages → Build and deployment выберите Deploy from a branch, `main` и `/ (root)`. Подождите публикации ссылки.

## Состав
- `index.html` — разметка интерфейса.
- `style.css` — оформление, адаптивность и анимации.
- `game.js` — сюжет и игровые механики.
- `assets/` — фоновая сцена и пять стилизованных портретов.

## Важно
Персонажи пока представлены **статичными портретами**, не отдельными прозрачными спрайтами. Выражения обозначаются подписями и эффектами. Музыка синтезируется браузером. Для публичной публикации с узнаваемыми реальными людьми желательно получить их согласие.

## Обновление 1.2
Судья Агафонов теперь использует шесть отдельных стилизованных портретов из предоставленного листа эмоций. Выражение автоматически выбирается по содержанию реплики. Изображения вписываются в область без обрезки и без подписей концепт-листа.


## Версия 1.3
- Все пять основных персонажей используют отдельные чистые портреты из исходных концепт-листов, без подписей и миниатюр соседних кадров.
- Добавлены шесть портретов-эмоций для Самохина, подсудимого, Натали и Баронессы.
- Убрана растягивающаяся пустая часть сцены; оптимизированы переносы текста и адаптивная высота.
- Переключение выражений по ключевым сценам (дальнейшая ручная режиссура эмоций возможна).
