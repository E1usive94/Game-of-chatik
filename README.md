# Дело № 4954 — версия 1.6 «Кинематографичная история»

Линейная визуальная новелла по мотивам переписки чата «Общение».

**Запуск:** откройте `index.html`. Для GitHub Pages загрузите содержимое архива в корень репозитория и включите Pages для ветки main.

**Управление:** «Далее», нажатие на сцену, пробел или Enter. Редкие выборы меняют только ближайшую реакцию. «Протокол» показывает прочитанные реплики.

**Изменения:** новая компоновка сцены для смартфонов, плавное появление персонажей, заставки глав, необязательные звуковые сигналы, сохранение выбора без изменения массива сюжета.

**Ограничения:** портреты взяты из ранее подготовленных концепт-артов; полноценные независимые спрайты ещё не созданы. В истории есть художественные реплики.
